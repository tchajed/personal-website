# chajed.io

Tej Chajed's personal website, built as a static site with [Vite](https://vite.dev/).

## Develop

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Vite writes the production site to `dist/`. For Cloudflare Pages, use `npm run build` as the build command and `dist` as the output directory.
