# chajed.io

Tej Chajed's personal website, built as a static site with [Vite](https://vite.dev/).

## Develop

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
```

Vite writes the production site to `dist/`. For Cloudflare Pages, use `bun run build` as the build command and `dist` as the output directory.
